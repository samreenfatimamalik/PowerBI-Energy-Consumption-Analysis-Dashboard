# PowerBI-Energy-Consumption-Analysis-Dashboard
Interactive Power BI dashboard for Energy Consumption Analysis with anomaly detection, KPI cards, time-series visualization, customer filtering, and meter-wise insights.

---


##  Features

- Total Energy Consumption KPI
- Average Energy Consumption
- Maximum Consumption
- Minimum Consumption
- Energy Consumption Trend Over Time
- Anomaly Detection Visualization
- Customer-wise Filtering
- Meter-wise Filtering
- Timestamp Filtering
- Interactive Power BI Dashboard

---

##  Dashboard Insights

The dashboard helps users:

- Monitor overall electricity consumption
- Detect abnormal energy usage
- Compare normal vs anomalous readings
- Analyze consumption trends over time
- Filter data by customer, meter, and timestamp
- Support data-driven decision making

---

##  Tools Used

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)

##  How to Use

1. Download the repository.
2. Open **mainDASHBOARD.pbix** using Microsoft Power BI Desktop.
3. Explore the interactive dashboard.
4. Apply filters to analyze different customers, meters, and timestamps.
